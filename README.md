# airbnb-nyc-data-analysis

## Описание задачи и цели проекта:

В данном проекте проводится анализ данных о размещениях Airbnb в Нью-Йорке. Датасет содержит информацию об объявлениях, включая тип жилья, район расположения, цену, количество отзывов и доступность объектов в течение года.

Основная задача проекта- изучить рынок краткосрочной аренды, определить факторы, влияющие на цену и популярность объявлений, а также понять, какие параметры
важны для клиентов при выборе жилья.
В результате анализа планируется получить практические выводы о структуре рынка
Airbnb и сформулировать рекомендации на основе выявленных закономерностей.

## Описание данных:
Источник:Kaggle
https://www.kaggle.com/datasets/dgomonov/new-york-city-airbnb-open-data
В рамках проекта используется датасет, содержащий информацию об объявлениях
сервиса Airbnb в Нью-Йорке за 2019 год.
